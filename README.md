# 课程定时答题与签到

适用于好医生继续医学教育等在线课程。每三分钟检查指定课件，处理过程题、学习签到和暂停续播；正常播放时保持安静。

## 安装

将仓库中的 [skill.md](skill.md) 安装到技能目录时命名为 `course-watch-and-answer/SKILL.md`。也可让支持技能安装的 AI 工具安装本仓库：

```text
安装 skill https://github.com/whitewatercn/auto-course-watch-and-answer/
```

## 使用

提供完整课件链接和指定浏览器或标签，例如：

```text
使用 course-watch-and-answer，监控这个课件：<完整课件URL>。
使用 Codex 应用内浏览器，每三分钟检查一次。
```

如需考试及后续课件衔接，请明确授权：

```text
发现待考试时完成本节考试，通过后按顺序继续同一项目的下一未完成课件。
每个课件设置独立三分钟监控，下一任务确认启用后停用当前任务。
```

监控会同时检查完整页面弹窗、签到和实际播放时间。签到弹窗关闭不代表考勤已确认；视频到终点不代表课程完成；待考试不算完成。考试答案需依据课件或可靠来源核实，无法核实时通知用户。学习完成也不代表已申请学分、付款或领取证书。

本仓库提供技能指令，不包含独立后台程序；定时运行依赖使用工具提供的 heartbeat 能力。登录、验证码、协议和付款按工具适用规则由用户处理。完整流程见 [skill.md](skill.md)。
